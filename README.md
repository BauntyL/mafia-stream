# Веб-Мафия для стримов

Онлайн-игра «Мафия» для стримеров: игроки заходят в браузере, стример показывает красивую сетку камер в OBS.

## Быстрый старт (локально)

```bash
# Установка
npm install
cd client && npm install && cd ..
cd server && npm install && cd ..

# Запуск (сервер + сайт одновременно)
npm run dev
```

- **Сайт:** http://localhost:5173
- **Сервер:** http://localhost:3001

## Как играть

1. Откройте сайт, введите **никнейм**.
2. **Создайте лобби** или **войдите по коду**.
3. В лобби:
   - Выберите **ведущего** (голосование или назначение создателем).
   - Каждый игрок нажимает **«Включить камеру»** — откроется VDO.Ninja.
   - Когда собралось **минимум 6 игроков** (без ведущего), ведущий жмёт **«Начать игру»**.
4. Игра идёт по фазам: ночь → день → голосование.
5. У каждого игрока своя **карта роли** и **подсказки**.

## Настройка OBS (для стримера)

1. В лобби нажмите **«OBS ссылка»** или скопируйте:
   ```
   https://ваш-сайт.ru/overlay/КОД_ЛОББИ
   ```
2. В OBS Studio: **Источники → + → Browser Source (Браузер)**.
3. Вставьте ссылку оверлея.
4. Укажите размер: **1920 × 1080**.
5. Поставьте галочку **«Обновить браузер при активации сцены»**.
6. Готово — зрители видят сетку камер как на профессиональных стримах.

### Советы для OBS

- Если видео не грузится: отключите аппаратное ускорение в OBS или добавьте `&codec=h264` к ссылкам VDO.Ninja.
- Оверлей обновляется автоматически при смерти/изгнании игроков.
- Ведущий по умолчанию **не показывается** в сетке (можно включить в настройках лобби).

## Деплой на Railway

1. Зарегистрируйтесь на [railway.com](https://railway.com).
2. Создайте проект из этого репозитория.
3. Railway автоматически соберёт и запустит приложение.
4. Переменные окружения (опционально):
   - `PORT` — порт (Railway задаёт автоматически)
   - `NODE_ENV=production`
5. Откройте выданный URL — это ваш сайт для игроков.

Команды сборки (уже настроены в `railway.toml`):
- **Build:** `npm run build`
- **Start:** `npm start`

## Технологии

- **React + Vite** — интерфейс
- **Socket.io** — игра в реальном времени
- **VDO.Ninja** — веб-камеры без своих серверов видео
- **Framer Motion** — анимации
- **Tailwind CSS** — стили
