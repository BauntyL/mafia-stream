# Веб-Мафия для стримов

Онлайн-игра «Мафия» для стримеров: игроки заходят в браузере по коду лобби, а стример выводит красивую сетку камер в OBS.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/BauntyL/mafia-stream)

## Что умеет

- Лобби по коду, выбор ведущего
- Камеры игроков через VDO.Ninja — без установки программ
- Роли: мирный житель, мафия, дон, шериф, доктор
- Фазы ночь / день / голосование под управлением ведущего
- Отдельный экран `/overlay/КОД` для OBS с карточками выбывших

## Быстрый старт (локально)

```bash
npm install
npm install --prefix client
npm install --prefix server

npm run dev
```

- Сайт: http://localhost:5173
- Сервер: http://localhost:3001

## Как играть

1. Откройте сайт и введите никнейм.
2. Создайте лобби или войдите по коду.
3. В лобби выберите ведущего и включите камеры.
4. Когда собралось минимум 6 игроков (не считая ведущего), ведущий начинает партию.
5. Ведущий листает фазы, игроки делают ходы и голосуют.

## Настройка OBS

1. В лобби скопируйте ссылку «Экран OBS» — она выглядит как `https://ваш-сайт/overlay/КОД`.
2. В OBS: **Источники → + → Браузер**.
3. Вставьте ссылку, укажите размер **1920 × 1080**.
4. Включите «Обновить браузер при активации сцены».

Если видео не появляется, отключите аппаратное ускорение в OBS.

## Выкладка на Render (бесплатно)

1. Нажмите кнопку **Deploy to Render** выше.
2. Войдите или зарегистрируйтесь (можно через GitHub).
3. Render прочитает `render.yaml` и сам настроит сборку — нажмите **Apply**.
4. Через 3–5 минут получите адрес вида `https://mafia-xxxx.onrender.com`.

Особенности бесплатного тарифа: сервис засыпает после 15 минут полной тишины, первый вход после сна занимает около минуты. Пока идёт партия, соединения активны и сервис не засыпает. Лобби хранятся в памяти, поэтому после перезапуска сервера незавершённые партии пропадают.

## Структура

```
mafia/
├── client/       # React: лобби, игра, экран для OBS
├── server/       # Node.js + Socket.io: комнаты, роли, фазы
├── render.yaml   # Конфиг деплоя на Render
└── railway.toml  # Конфиг деплоя на Railway
```

## Технологии

React, Vite, TypeScript, Tailwind CSS, Framer Motion, Socket.io, Express, VDO.Ninja.
